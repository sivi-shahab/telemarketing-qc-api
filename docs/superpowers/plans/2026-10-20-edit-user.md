1. User tidak ada, atau aktor tanpa `ADMIN_USER_WRITE` dan target bukan `_is_telemarketing_qc` → 404 `"User tidak ditemukan"`.
2. Normalisasi: username/email/name di-strip; username/email kosong bila dikirim → 422 `"Username dan email tidak boleh kosong"`. Password `""`/None = tidak berubah.
3. `role` dikirim dan ≠ role sekarang: tanpa `ADMIN_USER_WRITE` → 403 `"Hanya Admin yang dapat mengubah role"`; target = diri sendiri → 400 `"Tidak dapat mengubah role akun sendiri"`; role tidak ada di tabel `roles` → 422 `"Role '<x>' tidak dikenal"`.
4. Bentrok: user lain (`User.id != user_id`) dengan `lower(username) == lower(new)` atau `lower(email) == lower(new)` → 409 `"Username atau email sudah digunakan"`.
5. Hitung field yang berubah (username/email/name dibanding apa adanya sesudah strip; password berubah bila diisi). Tidak ada → kembalikan item tanpa commit.
6. Terapkan: bila username berubah → `crud.rename_username(db, old, new)` lalu set `user.username`; role `qc`→lain → `left_qc_at = utcnow()`, lain→`qc` → `left_qc_at = None`; password → `hash_password`. Tambah satu `UserChangeEvent` per field (`target_username` = username sesudah perubahan; `actor_*` dari `current_user`, `actor_user_id` None bila id 0). Satu `db.commit()` di akhir; exception apa pun → `db.rollback()` lalu raise.
